# DSA-CPP

A collection of Data Structures and Algorithms implemented in C and C++ for learning, practice, and interview preparation.

This repository contains beginner-friendly implementations of commonly used sorting and searching algorithms, with a focus on clarity, correctness, and understanding of core concepts.

## Contents

- Quick Sort in C
- Selection Sort in C
- Insertion Sort in C
- Iterative Binary Search in C++

## Repository Structure

```text
DSA-CPP/
├── BSiterative.cpp
├── insertionsort.c
├── quicksort.c
├── selectionsort.c
├── structure.cpp
├── README.md
```

## About the Code

Each file is designed to be easy to read and study. The implementations are useful for:

- learning algorithm logic
- practicing problem-solving
- revising interview fundamentals
- understanding how sorting and searching work in C/C++

## How to Use

Compile and run any file using a C/C++ compiler.

Example:

```bash
g++ BSiterative.cpp -o binary_search
./binary_search
```

or

```bash
gcc quicksort.c -o quicksort
./quicksort
```

## Notes

This project is intended for educational purposes and is best suited for beginners and students who want to strengthen their understanding of fundamental algorithms.
